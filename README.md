# Blog em Angular

Blog construído com Angular 16: componentes reutilizáveis (menu, cards grandes e pequenos), rotas e página de conteúdo que carrega o post pelo identificador.

Projeto de estudo de 2023 (Angular / TypeScript), mantido aqui como registro da minha evolução.

## Como rodar

```bash
npm install
npx ng serve   # http://localhost:4200
```

## O que pratiquei

- Componentes, `@Input` e comunicação entre eles
- Rotas e parâmetros de rota
- Organização de um projeto Angular
